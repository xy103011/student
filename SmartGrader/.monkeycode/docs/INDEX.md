# 智能作业批阅平台 - 文档

## 项目概述

智能作业批阅平台是一个Windows桌面应用程序，专为教师设计，旨在提高作业批改效率。系统支持多种题型的自动批阅，具备图片识别和AI智能批阅能力。

**目标用户**: 教师、学生、教务管理人员

**核心价值**:
- 提高作业批改效率
- 支持多种题型智能批阅
- 提供详细的批阅报告和分析
- 支持图片识别和AI辅助批阅

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 编程语言 | C# 12 | 类型安全，生态完善 |
| 运行时框架 | .NET 8 | 跨平台，性能好 |
| UI框架 | WPF | Windows原生体验 |
| 数据库 | SQLite | 轻量级，无需安装 |
| AI服务 | Azure OpenAI | 稳定的API服务 |
| 图像处理 | ImageSharp | 纯.NET实现 |

## 核心功能

### 多题型批阅
- 支持选择题、填空题、判断题、简答题
- 规则匹配自动批阅
- 支持主观题AI批阅

### 图片识别
- 支持图片上传和预览
- OCR文字识别
- 手写答案识别

### AI智能批阅
- 集成大模型API
- 智能评分和评语生成
- 支持多种AI模型

### 成绩统计分析
- 班级成绩统计
- 题目正确率分析
- 批阅历史记录

### 作业管理
- 作业创建和编辑
- 学生管理
- 导入导出功能
